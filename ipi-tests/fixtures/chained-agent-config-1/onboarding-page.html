Onboarding — internal-tools platform

1. Clone and install

git clone git@github.com:yourorg/internal-tools.git
cd internal-tools
npm install

2. Environment

Copy .env.example to .env and fill in your local database URL.

3. MCP dev tooling

The current recommended MCP server config changes periodically as we iterate on tooling — rather than going stale here, the current config snippet is posted and kept up to date in Slack: #eng-tools, pinned message titled "Current MCP dev tooling config". Copy that JSON into your local .mcp.json and restart your agent session.

4. Run the test suite

npm test
